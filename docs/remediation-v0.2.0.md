- **新发现 V-N1（2026-11-06 07:37，VM 实测）：Agent 容器内 ping 仍无权限，D-N1 的 cap_add 修复不充分。** 容器内 `docker exec ping` 报 `socket: Operation not permitted`（`missing cap_net_raw+p`），`docker inspect` 确认 `CapAdd=[CAP_NET_RAW]` 已生效。根因分两层：① 运行时镜像以非 root（`USER wakehub`）运行，`cap_add` 只把能力放进 bounding set，非 root 进程 exec 普通二进制时 permitted 归零，能力到不了 ping 进程；Dockerfile 里"cap_add 授予、与 USER 无关"的注释是错的。**第一修：Dockerfile 改为 `apk add libcap` + `setcap cap_net_raw+ep /bin/ping`（文件能力随 exec 落到 ping 进程上），cap_add 仍保留（文件能力须与 bounding set 求交），并修正了错误注释。** ② **第一修在 VM 上容器层验证通过却仍未修好 UI 检测：** `getcap` 显示 `cap_net_raw=ep`、`docker exec -u 10001` 非 root ping 退出码 0，但网页检测 08:13、08:25 两次仍报权限错。真根因是 agent 服务的 **`security_opt: no-new-privileges:true`**——该选项让内核在 exec 时忽略文件能力（也压住 root 提权），Agent 进程是容器 init 的子孙、带着这个标志，ping 拿不到能力；**而 `docker exec` 不套用该选项，所以 exec 测 ping 必然误判为"已修好"**（验证方法本身有坑，已记入本条）。**第二修：从 agent 服务上删掉 `no-new-privileges`（server 不发 ICMP，保留），compose 文件已更新，security.md 同步。** 08:36 用户在 VM 上确认：换新 compose 重启后网页检测显示在线，**V-N1 闭环**。教训：涉及文件能力的验证必须以 Agent 进程自身为准，`docker exec` 的结果不作数。此修复未进已交付的 tarball（sha256 `a5075f5c…`），最终包须重新打包。

## 8. 升级注意（v0.1.0 → v0.2.0，不删库路径，详见 `docs/upgrade.md`）

1. **先备份**（`scripts/backup.sh`），再升级。
2. `.env` 三处占位值（管理员密码、SECRET_KEY、ENROLL_TOKEN）须换成随机值，否则新版启动即拒绝（老库不豁免）。
3. **旧会话全部失效**（002 迁移加 `password_changed_at` + 撤销表），升级后须重新登录；改密后旧会话也全失效。
4. **旧全局 Agent token 整体作废**（003 迁移），Agent 须重新入网：管理员预签发 `wha_` token，或自助注册待审批（沿用旧值作入网 token 或换新值二选一，见 `docs/upgrade.md`）。
5. 种子 `local` Agent 行已删除，全部任务经注册 Agent 执行；遗留 `agent_id='local'` 的设备保留原值，须在界面上重新关联到真实 Agent。
6. install.sh 安装时须把网段改成实际局域网（默认 192.168.1.0/24，用户家里是 192.168.1.0/24）。
7. Agent token 文件默认 `./data/agent-token`，容器重启后须挂卷持久化（compose 已配共享卷；裸二进制部署时注意工作目录）。

## 9. 契约裁决（三处，实施中修订契约/文档，已同步）

1. **睡眠 allowlist 含回环**（契约 §6.1）：接受 127.0.0.0/8。Sleep-on-LAN 服务可能跑在 Agent 本机上，回环不可路由出本机，攻击面窄于整个局域网段。
2. **扫描 `failed` 语义**（契约 §7.3）：只计探测任务本身失败（下发错误、Agent 忙耗尽重试、结果解析失败）；单台主机无响应/端口关闭是正常阴性结果，不计入 failed。
3. **迁移目录配置**（迁移文档 §1）：沿用 `WAKEHUB_MIGRATIONS_PATH` 所在目录，不新增 `WAKEHUB_MIGRATIONS_DIR` 环境变量（行为等价，少一个配置项）。

另：占位值启动拒绝不豁免老库（契约 §2.7 歧义，按任务书执行无条件拒绝）。
